# Printsakes Studio PRO — Luxury Photobook Engine

> **"Everyone has the photos. Nobody has the book."**  
> An elevated, production-ready heirloom photobook creation platform tailored for celebrants, couples, event planners, and luxury photography studios.

---

## 🌟 Key Features

### 📖 Immersive 3D Virtual Studio
* **Interactive 3D Spread Viewer**: Realistic page-turn physics with spine shadows, depth crease, and custom view angles.
* **Bird’s-Eye Grid Proof Mode**: Instant panoramic view of all spreads to reorganize, sequence, duplicate, and balance the narrative.
* **Tactile Web Audio Feedback**: Subtle, synthesized paper-rustle sound on every page turn and shutter clicks on photo selection (with mute toggle).

### 🎨 Bespoke Finishes & Archival Materials
* **4 Luxury Cover Finishes**:
  * *Velvet Matte Hardcover* (Anti-scuff laminate with full wrap-around photo front & back)
  * *Italian Woven Linen + Hot Foil* (Milanese linen with Gold, Silver, or Rose-Gold metallic stamping)
  * *Artisan Bonded Leatherette* (Rich grain with deep blind-debossed monogram crest)
  * *Crystal Acrylic Glass Front* (4mm diamond-polished museum acrylic front)
* **3 Archival Paper Stocks**:
  * 250 gsm Archival Pearl Lustre
  * 270 gsm Fine Art Velvet Matte Cotton
  * 420 gsm Seamless 100% Panoramic Layflat Board

### 👥 Celebrant & Event Organizer Super-Powers
* **Live Event QR Placard & Mobile Drop**: Generate and print elegant QR tabletop cards for banquet tables. Guests simply aim their smartphone cameras to upload candid photos and heartfelt blessings directly into the book—no app download required.
* **Organizer Moderation Inbox**: Review incoming guest photos live during the reception, approving or declining with 1-click.
* **1-Click WhatsApp Client Proofing**: Generate a private, interactive 3D proof link for clients to review and sign off with a verified digital approval stamp.
* **Pre-Flight PrintCheck Pro Engine**: Automated DPI resolution audit (flags compressed WhatsApp photos), 3mm bleed margin safety guidelines, and spine gutter clearance inspection.
* **Scannable Audio Voice Keepsakes**: Embeds Spotify-style soundwaves and QR codes to preserve the couple's spoken vows or parental blessings in the physical book.
* **Wholesale Multi-Copy Calculator**: Tiered discounts (10% to 25% off) for ordering master couple albums plus miniature parent keepsake editions.

### 💳 Nigerian & International Checkout
* Direct Nigerian Bank Transfer simulation with instant automated account reconciliation and reference codes.
* Debit card & Paystack gateway simulation.
* Express doorstep courier delivery across Lagos (Island & Mainland), Abuja Priority, Nationwide Inter-State, and DHL Worldwide.

## 🛠️ Tech Stack

* **Frontend**: React 19, Vite, TypeScript/JSX
* **Styling**: Tailwind CSS v4, Custom 3D CSS Transforms & Lighting Shaders
* **Icons & Animation**: Lucide React, Canvas Confetti
* **Audio Synthesis**: Web Audio API (zero external asset dependencies)

## 🚀 Getting Started

### 1. Clone the repository
```bash
git clone https://github.com/ebtaryoh/OnlinePhotoBook.git
cd OnlinePhotoBook
```

### 2. Install dependencies
```bash
npm install
```

### 3. Start development server
```bash
npm run dev
```

### 4. Build for production
```bash
npm run build
```
